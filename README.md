# Uni Ai Pal

create a mobile app where the user has to log in through a google account. then the user chooses their university and major. then the app shows the user every subject A-Z at the university where they can search the subject (which is taught in their university) they want to explore. when they click it, they should see practice and ask AI. practice would give them detailed practice questions with easy/medium/hard difficulty each about 30 questions on each difficulty level. there also should be tests from last years and they should receive feedback on each question they answer, with what they did right and what they did wrong. there also should be topics that are covered by AI to make it easier for the said student to even study at that app. there should be some practice material from the university they are in and if not available it should say "see similar uni's tests" and list some top unis like MIT Stanford or top 20 in the US. in the ask AI part of the subject, it should recieve a prompt from the user, like if the user is interested in how much credits it has, ai should answer. or if they want to ask any question about that subject, AI should answer
